# GitHub Organization Defaults

This repository contains shared GitHub configuration and community health files for our development organization.

## Purpose

Our goal is to maintain consistent engineering practices across projects without introducing unnecessary processes.

 These defaults help standardize:

 - Pull request descriptions
 - Contribution guidelines
 - Bug reports and improvement requests
 - Security vulnerability reporting
 - Support and technical questions

## How Defaults Work

GitHub automatically uses supported community health files from this repository when an organization repository does not define its own equivalent.
