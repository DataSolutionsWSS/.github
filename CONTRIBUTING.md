# Contributing Guidelines

These guidelines apply to development repositories in our GitHub organization unless a repository defines its own contributing instructions.

Our goal is to maintain a simple, consistent, and collaborative development workflow.

## 1. Project Management

Asana is our primary source of truth for project management.

Use Asana for:

- Tasks and assignments
- Priorities and deadlines
- Project planning and status
- Cross-functional coordination

GitHub is used for source control, code reviews, automated checks, releases, and technical discussions.

Do not create a GitHub Issue for every Asana task. Create GitHub Issues when they provide additional technical value.
