# Support

## Internal Development Questions

For questions about active development work, use the team's existing communication channels or the relevant Asana task.

Examples include:

- Project requirements
- Task priorities
- Assignment questions
- Delivery timelines
- Project status

## Repository-Specific Technical Questions

For questions related to a repository:

1. Read the repository's README and documentation.
2. Review existing issues and pull requests when relevant.
3. Contact the developers currently assigned to the project.
4. Create a GitHub Issue if the discussion would benefit from being tracked alongside the code.

## Bugs and Improvements

Use the repository's GitHub Issue templates when reporting technical bugs or proposing repository-specific improvements.

For planned development work, Asana remains the primary source of truth.

## Security Issues

Do not report security vulnerabilities through public issues.

Follow the instructions in `SECURITY.md`.

## External Support

These repositories are not necessarily public support channels for company products.

For customer support or account-related questions, use the official support channels provided by the relevant product or service.
